# 잡BTI

> 나한테 맞는 직무는 뭘까? 12문항으로 알아보는 잡BTI

게임 느낌의 직무 유형 테스트예요. 12문항에 답하면 8가지 유형 중 하나로 **사원증**이 발급되고, 인스타그램 스토리 크기(1080×1920) 이미지로 저장할 수 있어요.

## 구성

- **시작 화면**: 픽셀 사무실 애니메이션, 사원증 8종 미리보기
- **질문 12개**: 전공 계열, 관심 분야(최대 3개), 취미, 보유 자격증, 좋아하는 드라마, 상황형 질문 7개
- **결과**: 스토리용 사원증 이미지, 어울리는 직무 3개, 추천 자격증(이미 가진 자격증은 제외), 추천 대외활동, 유형별 스탯

| 유형 | 어울리는 직무 |
| --- | --- |
| 아이디어 뱅크형 | 기획, 마케팅 |
| 감성 크리에이터형 | 디자인, 콘텐츠 |
| 논리 설계자형 | IT, 개발 |
| 든든한 살림꾼형 | 사무, 경영지원 |
| 인싸 해결사형 | 영업, 서비스 |
| 따뜻한 멘토형 | 교육, 상담, 복지 |
| 글로벌 탐험가형 | 무역, 관광, 해외 |
| 분석 탐정형 | 데이터, 연구 |

**히든 유형: 야망 사업가형** — 창업 성향이 강한 답을 많이 고르면 사원증 대신 "축하합니다! 창업에 당첨되셨습니다"와 함께 대표이사 명함이 발급돼요.
